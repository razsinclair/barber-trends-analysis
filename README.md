Key Findings
Skit content generated the highest average views (~14M)
Transformation videos also performed strongly (~13M)
Tutorials had lower reach but solid engagement (~5–6%)
High views do not always equal high engagement
These findings suggest it is optimal for content creating barbers to produce skits/funny videos and transformations to maximise both visibility and audience interaction.

Limitations
Small sample size
Data collected manually
Results may vary across platforms/time periods
Data collected from only 2 social media platforms
